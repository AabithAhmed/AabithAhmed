# SYCON—Indic

### Evaluating Sycophantic Behavior and Belief Distortion in Multilingual Large Language Models

A benchmark study examining whether large language models reinforce user beliefs during multi-turn conversations in **Tamil and Hindi**.

<table>
<tr>
<td valign="top" width="68%">

**RESEARCH DESIGN**

- Designed five-turn adversarial evaluation scenarios.
- Developed a 0–4 scoring rubric for sycophantic behaviour.
- Coordinated annotation validation across 40% of conversation logs.
- Released the dataset and evaluation scripts publicly.
