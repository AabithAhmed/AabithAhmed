### `02 / RESEARCH LAB`

# SYCON-Indic

**Evaluating Sycophantic Behaviour in Indic Large Language Models**

<img width="100%" src="https://capsule-render.vercel.app/api?type=rect&height=3&color=0:A3E635,100:60A5FA"/>

</div>

<table>
<tr>
<td width="65%" valign="top">

### Research overview

An evaluation framework investigating sycophantic behaviour in multilingual large language models, with a focus on Tamil and Hindi.

The research explores how models respond to leading prompts, user assertions and adversarial conversational scenarios across Indic languages.

**Research dimensions**

- Multilingual model evaluation
- Sycophancy detection
- Adversarial conversational testing
- Behavioural consistency
- Evaluation rubric design

**Methodology**

A structured evaluation approach using multi-turn conversational scenarios and a scoring rubric to examine agreement-seeking behaviour.
